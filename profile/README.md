# VeloxRouter

> A high-performance, minimalist PHP router framework inspired by Go Fiber and Python FastAPI.

🔗 **[Access the Official Documentation](https://veloxrouter.github.io/docs/)**

## 🚀 About

**VeloxRouter** is a lightning-fast, lightweight HTTP routing engine built for modern PHP 8.2+. Designed with simplicity, developer experience, and performance in mind, it provides a clean API for building robust web applications and RESTful APIs without unnecessary bloat.

## 📦 Installation

Install the package via Composer:

```bash
composer require veloxrouter/router

```

## 🏛️ Ecosystem

VeloxRouter is a modular ecosystem built for modern PHP 8.2+, designed for speed, developer experience, and zero unnecessary bloat.

| Repository | Description | Installation |
| --- | --- | --- |
| **[`router`](https://github.com/VeloxRouter/router)** | Lightning-fast HTTP routing engine | `composer require veloxrouter/router` |
| **[`middlewares`](https://github.com/VeloxRouter/middlewares)** | Enterprise-grade middleware collection | `composer require veloxrouter/middlewares` |
| **[`sse`](https://github.com/VeloxRouter/sse)** | Zero-dependency Server-Sent Events | `composer require veloxrouter/sse` |
| **[`validator`](https://github.com/VeloxRouter/validator)** | Lightweight multi-language validation engine | `composer require veloxrouter/validator` |
| **[`rpc`](https://github.com/VeloxRouter/rpc)** | JSON-RPC 2.0 microservices communication | `composer require veloxrouter/rpc` |
